# LLibrary port: ready on branch iaf/llibrary (git fetch origin iaf/llibrary && git merge origin/iaf/llibrary)
- 1.12 vanilla model classes: net.ilexiconn.llibrary.client.model.legacy.{ModelBase, ModelRenderer, ModelBox, TexturedQuad, PositionTextureVertex, TextureOffset}, 1.12 field names. ModelBase extends EntityModel<Entity>: use in a MobRenderer with `super(ctx, (EntityModel) model, shadow)`; prepareMobModel -> setLivingAnimations; renderToBuffer -> 1.12 render(entity, limbSwing, amount, age, yaw, pitch, 0.0625F). Layers/BERs: model.renderLegacy(pose, buffer, light, overlay, argb, entity, ..., scale).
- LegacyRender replaces GlStateManager in model code (pushMatrix/popMatrix/translate/scale/rotate/color; push(pose, vc, light, overlay, argb)/pop(); setBuffer to switch RenderType). Use entityCutoutNoCull; AdvancedModelRenderer.opacity needs a translucent RenderType.
- Model tools: client.model.tools.{AdvancedModelBase, AdvancedModelRenderer, ChainBuffer(LivingEntity)}; client.model.{ModelAnimator, Transform}.
- Animation: server.animation.{Animation, IAnimatedEntity, NamedAnimation, AnimationAI (Goal)}; AnimationHandler.INSTANCE.updateAnimations(entity) every tick both sides; sendAnimationMessage server side; AnimationEvent.Start/.Tick on NeoForge.EVENT_BUS; LLibrary.PROXY.getPartialTicks().
- Tabula: TabulaModelHandler.INSTANCE.loadTabulaModel("/assets/iceandfire/models/tabula/firedragon/dragonFireGround") (classpath); TabulaModel, ITabulaModelAnimator. IceAndFireTabulaModel is IaF code (dragon-client ports it).
- Network: server.network.{AbstractMessage<T> (CustomPacketPayload; keep no-arg ctor + fromBytes/toBytes(ByteBuf)), SimpleNetworkWrapper (sendToServer/sendTo/sendToAll/sendToAllAround(TargetPoint)/sendToAllTracking/sendToDimension), MessageContext, ByteBufUtils}. Handlers onClientReceived(Minecraft, T, Player, MessageContext) / onServerReceived(MinecraftServer, T, Player, MessageContext) on the main thread. iaf/core: `@NetworkWrapper({...}) public static SimpleNetworkWrapper NETWORK_WRAPPER;` + `NetworkHandler.INSTANCE.injectNetworkWrapper(IceAndFire.class, "iceandfire")` in the IceAndFire constructor (messages registered at mod construction). Keep client-only code out of message classes (separate class called from onClientReceived).
- Entity properties: EntityPropertiesHandler.INSTANCE.registerProperties/getProperties; saveNBTData/loadNBTData take CompoundTag; stored in attachment llibrary:entity_data, synced like 1.12. 1.12 quirk kept: init() never runs (getEntity()/getWorld() null), so FrozenEntityProperties.setFrozenFor also freezes ice dragons.
- Multipart: server.entity.multipart.{PartEntity(Mob parent, radius, angleYaw, offsetY, sizeX, sizeY, damageMultiplier) extends NeoForge PartEntity<Mob>, IMultipartEntity (getParts(); entity must override isMultipartEntity() -> true; onUpdateParts ticks parts)}. Dragons: assign part ids in the parent's setId like the 1.21 ender dragon so client hits on parts reach the server.
- Utils: client.util.ClientUtils (interpolate...), ItemTESRContext (fill it yourself in renderByItem).
- 1.21 needs lowercase resource paths; .tbl files are read through the classpath, so the "Invalid path" warning is harmless.
